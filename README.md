# Paula Gaitán · Sitio web

Sitio personal de Paula Gaitán, mercadóloga, publicista y gerente de imagen en redes, con la información del curso virtual *Marketing Digital y Educación Financiera para Jóvenes y Emprendedores*.

## Estructura

```
index.html        estructura y contenido
css/styles.css    estilos (variables de marca en :root)
js/main.js        interacciones; datos editables en el objeto CONFIG
img/              fotos, logo y código QR
netlify.toml      configuración de publicación en Netlify
```

## Editar datos rápidos

En `js/main.js`, objeto `CONFIG`: fechas del curso, enlace del formulario de inscripción, enlace del crédito de TYR y la opción para ocultar los textos pendientes.

## Publicación

Cada cambio que se sube a la rama `main` se publica automáticamente en Netlify.
